01 / REAL BOARDHardware tested*

ESP8266

Wemos D1 mini · 4 MB flash · L01-r15

A tiny network calculator you can program from your browser. Set up Wi-Fi once, then use a USB power supply and connect over your local network.

  • Serial and browser console with saved Wi-Fi
  • Script editor with computer-side Open/Save and Run/Stop
  • Digital GPIO, ADC input and cancellable delay
  • 16 variables; matrices up to 64 elements
Read the ESP8266 manual ↗

* Core workflows and LED output confirmed on L01-r14. Full peripheral and stress checks remain open. L01-r15 awaits board testing.

02 / EMULATORQEMU tested

ESP32-S3

N16R8 target · 16 MB flash / 8 MB PSRAM · E03

A larger serial workstation with FFTs and a foreground app launcher. Upload a separately compiled program, run it, and return to your mathematical workspace.

  • MatmMax console with 64×64 square matrices
  • FFT and a 4 MiB engine payload cap in PSRAM
  • External ELF apps uploaded over serial
  • Variables preserved when an app returns
Explore the ESP32-S3 build ↗

Physical board validation is pending. Uploaded programs are RAM-only and trusted native code.
