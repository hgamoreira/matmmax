MatmMax for DOS | 8086/CGA preview
=================================

MatmMax is the numerical program in the Mini-Max suite. This source preview
targets the Toshiba T2100. The built executable displays its original
MathSmith M08 name when it starts.

Start here
----------
1. Start DOS and extract or copy the files to a writable directory.
   A DOS-formatted 720 KB floppy is enough on a Toshiba T2100.
2. Change to that directory and enter MATHSMTH.
3. Try these lines at the prompt:

      A=[4 -2;-2 4];
      A\[2;8]

   The solution is the column 2, 3.
4. Type run primes to try a supplied script. Use edit hello to write
   a script, F2 to save, or F5 in the editor to save and run.
5. Type help or press F1 for the language guide. Type quit to return
   to DOS. For a line-by-line prompt, start with MATHSMTH /L.

Machine and display
-------------------
The reference machine is the Toshiba T2100 running DOS 3.30, with an
8086, 640 KB conventional RAM and a CGA-compatible display. Arithmetic
uses software floating point. Graphics plotting uses BIOS CGA mode 6
(640 by 200). For example, try plot(1:5,[3 1 4 1 5]). Press a key to
return from the graph. The IBM XT text-only and the IBM PS/1 486 VGA
builds have their own release and validation status.

In DOSBox-X, select a CGA display, mount the extracted directory as a
DOS drive, switch to that drive, and run MATHSMTH from the DOS prompt.
For example, replace the path below with the directory you extracted:

      MOUNT C /path/to/matmmax
      C:
      MATHSMTH

Files and optional AI
---------------------
Calculations, examples, scripts, editing and plots run offline. The
ask, code, explain, fix and why assistant commands require a separate
MSASK helper, DOS networking and a host server with Ollama. The optional
helper has separate setup instructions.

Validation
----------
The project confirmed core math, scripts and plotting on the actual
T2100 in earlier revisions. The later editor and assistant do not have
a complete physical PASS/FAIL record. The offline preview is tested
on the rebuilt M08 executable in DOSBox-X. Other physical DOS machines
with compatible hardware are candidates for testing.
